The day navigator is one card: arrows step a day at a time, the date itself opens a calendar picker, and Jump to today only appears when you're on an earlier day. The seven-day strip shows each day's close state at a glance (finalized, needs review, open, no entries) so an admin can spot an unreviewed day without paging back. Try the arrows and day tiles. Next is disabled on today; days after today never appear.

The topbar chip repeats the day's state so the admin sees Needs review without scrolling. The count, difference and arithmetic sit together so a shortage is read beside its causes.
